# The Traditional Craft Directory (TCD)
## Centralized Digital Platform for India's Traditional Artisans & Craft Communities

> Developed in alignment with guidelines from the **Ministry of Textiles, Government of India**, the **Office of the Development Commissioner (Handicrafts)**, and **Unified Mentor**.

---

## 🌟 Overview & Problem Statement

Traditional artisans in India face severe structural obstacles:
- **Middlemen Exploitation:** Commercial intermediaries pocket 60%–80% of final sales margins while artisans earn subsistence wages.
- **Digital Invisibility:** Over 90% of genuine master craftspersons lack indexed digital presence, workshop locations, or contact points.
- **Powerloom & Counterfeit Imitations:** Machine reproductions undercut genuine handcrafts.
- **Lack of Verified Directories:** Institutional buyers, museum curators, architects, and conscious patrons struggle to discover authentic master craftspersons directly.

**The Traditional Craft Directory (TCD)** provides a centralized, government-standard digital infrastructure designed to document, promote, verify, and connect India's artisans directly with patrons and institutions with **₹0.00 platform commission (100% direct)**.

---

## 🎯 Key Objectives

- **Centralized Directory:** Document authentic master craftspersons across 28 States and Union Territories.
- **Middleman Disintermediation:** Direct phone numbers, WhatsApp chats, and workshop locations for every artisan.
- **Digital Documentation & Heritage Preservation:** Documenting endangered techniques, generational lineages, indigenous raw materials, and traditional tools before they disappear.
- **Government-Standard Verification:** Integration with Pehchan Artisan Cards, Shilp Guru rolls, and Geographical Indications (GI) Registry.
- **Direct Sourcing & Workshop Tourism:** Facilitating bespoke custom commissions and in-person workshop visits.

## 🛠️ Technology Stack

- **Frontend:** React 18, Vite 6, Tailwind CSS (Custom Heritage Palette), Lucide Icons, React Router 6.
- **Backend:** Node.js, Express.js REST API with CORS.
- **Database & Persistence:** File-based JSON state storage with dual-layer browser LocalStorage fallback for offline resilience.
- **Audio Engine:** Pure Web Audio API ambient loom shuttle & bronze chime soundscape synthesizer.
- **Design Tokens:** Festive Indian Jewel Tones (Peacock Indigo, Crimson, Marigold, Emerald, Gold Amber, Terracotta).

   - Fast filtering across Textiles, Pottery, Metalcraft, Folk Painting, Woodcraft, and Jewelry.

## 🚀 Running the Project Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Execution
```bash
# Clone and enter directory
cd /Users/smarikagupta/.gemini/antigravity/scratch/traditional-craft-directory

# Install all dependencies (Client + Server)
npm run install:all

# Option 1: Start Full-Stack Server (Serves React App + REST API on port 5001)
npm run server
# Access at: http://localhost:5001

# Option 2: Start Vite Client with Hot-Reloading (Port 5173 with proxy to backend)
npm run client
# Access at: http://localhost:5173
```
